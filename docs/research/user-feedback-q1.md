# Звіт: Дослідження відгуків користувачів Q1 (User Feedback Analysis)

Цей документ містить методологію збору зворотного зв'язку, ключові метрики та аналіз перших відповідей спільноти щодо роботи Smart File Sorter v2.0 у порівнянні з конкурентами.

## 📈 Метрики кампанії збору відгуків (План на 4 тижні)
- **Цільова кількість відповідей**: >150 коментарів у GitHub Discussions та Reddit.
- **Основні майданчики**: GitHub Discussions, r/macapps, Product Hunt Launch page.
- **Очікуваний результат**: Побудова пріоритетного беклогу розробки v2.1.

---

## 🔍 Попередній аналіз болючих точок конкурентів

На основі перших інтерв'ю з бета-тестерами та аналізу відгуків про **Hazel** та **CleanMyMac** виділено такі проблеми:

### 1. Hazel (Automation Tool)
* **Проблема складності UX**: Користувачі скаржаться на інтерфейс побудови правил у стилі 2010-х років. Багаторівневі AND/OR групи важко налаштовувати.
* **Рішення у нашому додатку**: Liquid Glass UI з візуальними картковими групами та готовими інтерактивними шаблонами в один клік.
* **Відсутність ШІ**: Hazel не вміє класифікувати файли за змістом чи зображенням.
* **Рішення у нашому додатку**: Локальні нейромережі CoreML (Image Classifier) та OCR для автоматичного розподілу.

### 2. CleanMyMac (System Cleaner)
* **Нав'язливість**: Постійні спливаючі вікна з нагадуваннями про очищення смітника та оперативної пам'яті.
* **Високе фонове навантаження**: Займає 200-400 МБ оперативної пам'яті в режимі менструального моніторингу.
* **Рішення у нашому додатку**: Сортування в реальному часі через легкі macOS FSEventsWatcher (фонове споживання <20 МБ RAM). Повна відсутність нав'язливого спаму сповіщень.

## 📂 Типова структура захаращення Downloads
За результатами опитування 50 ранніх тестерів, папка Downloads зазвичай містить:
1. **Тимчасові DMG/Zip інсталятори** (35% об'єму). Користувачі забувають їх видаляти після встановлення.
2. **Знімки екрана (Screenshots)** (20% кількості файлів). Створюють візуальний хаос.
3. **Робочі PDF та рахунки** (25% об'єму). Потребують структурованого архівавання.
4. **Неідентифіковані завантаження** (меми, випадкові картинки).

Це підтверджує правильність вибору нашої дефолтної стратегії з наявністю автоматичного розпізнавання скріншотів та архівації інсталяторів.
