# Шаблони GitHub Discussions для опитування користувачів (v2.0 Launch)

Цей документ містить готові шаблони для запуску обговорень у розділі Discussions нашого репозиторію GitHub перед фінальним ланчем на Product Hunt.

---

## 💬 Шаблон 1: "Які 3 функції найбільше потрібні?"
**Категорія**: `Ideas` / `Feature Requests`  
**Заголовок**: 🎯 Які 3 функції ви б додали наступними в Smart File Sorter? / What 3 features would you add next?

### Текст обговорення (UA):
```markdown
Привіт усім! 🚀

Ми готуємо велике оновлення Smart File Sorter v2.0 і хочемо побудувати roadmap на основі ваших потреб. 

Напишіть у коментарях **3 функції**, яких вам найбільше не вистачає у щоденному використанні додатку. 

Це може бути будь-що:
1. Нові ШІ-моделі для авто-сортування.
2. Специфічні дії (наприклад, інтеграція з Notion або Google Drive).
3. Покращення інтерфейсу (віджети, графіки).

Голосуйте лайками за ідеї інших користувачів — найпопулярніші ми візьмемо у розробку першими! 👇
```

### Text (EN):
```markdown
Hello everyone! 🚀

As we prepare the v2.0 major launch, we want to build our future roadmap around your actual needs. 

Please share **3 features** you want to see most in the upcoming releases of Smart File Sorter.

Whether it is a custom cloud integration (Notion, Dropbox), specialized AI rules, or visual widgets—we want to hear it. Upvote ideas you agree with! 👇
```

## 💬 Шаблон 2: "Покажи свій Downloads — як зараз сортуєш?"
**Категорія**: `Q&A` / `General`  
**Заголовок**: 📂 Покажи свій Downloads: хаос чи порядок? / Show your Downloads folder structure!

### Текст обговорення (UA):
```markdown
Папка `Downloads` (Завантаження) — це найгарячіше місце на будь-якому Mac. 🔥

Поділіться з нами:
* Скріншотом вашої папки Downloads (без конфіденційної інформації!).
* Як ви зазвичай сортуєте файли? (Вручну раз на тиждень, автоматичними скриптами, взагалі не сортуєте?).
* Які типи файлів займають найбільше місця?

Ваші відповіді допоможуть нам розробити найкращі дефолтні шаблони сортування в майстрі налаштувань! 💡
```

### Text (EN):
```markdown
The `Downloads` folder is often the messiest place on macOS. 🔥

We want to know:
* What does your Downloads folder look like? (Share a screenshot if you can!)
* How do you sort it? (Manually, custom shell scripts, or do you just leave it as is?)
* What file types hoard the most space?

Your configurations will help us design better default rules and onboarding templates! 💡
```

## 💬 Шаблон 3: "Що тебе бісить у Hazel/CleanMyMac?"
**Категорія**: `Polls` / `Feedback`  
**Заголовок**: ⚡️ Що вас найбільше дратує в Hazel або CleanMyMac? / Pain points with Hazel & CleanMyMac

### Текст обговорення (UA):
```markdown
Привіт, друзі! 

Ми створюємо альтернативу відомим продуктам для очищення та автоматизації диска. Щоб зробити Smart File Sorter кращим за конкурентів, нам важливо знати їхні слабкі сторони.

Поділіться своїм досвідом користування **Hazel** та **CleanMyMac**:
1. Що викликає найбільше роздратування? (Складний інтерфейс правил у Hazel, високе фонове споживання CPU в CleanMyMac, нав'язливі сповіщення?).
2. Яких функцій там немає, але вони дуже потрібні?
3. Чому ви шукаєте альтернативу?

Давайте створимо ідеальний інструмент разом! 🛠️
```

### Text (EN):
```markdown
Hi folks!

To make Smart File Sorter a truly superior alternative to legacy tools like **Hazel** and **CleanMyMac**, we want to address their biggest design and functional flaws.

Let us know:
* What annoys you most about Hazel or CleanMyMac? (Hazel's complex old-school rules builder, CleanMyMac's high background RAM usage or persistent notifications?)
* What critical features are missing in those apps?

Let's build the ultimate macOS utility together! 🛠️
```
