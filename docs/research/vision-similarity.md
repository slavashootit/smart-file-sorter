# Звіт R2: Якість Vision Feature Print для Similar Photos на macOS

Ми провели дослідження поведінки та точності роботи Apple Vision `VNGenerateImageFeaturePrintRequest` для знаходження схожих зображень (near-duplicates) з різними спотвореннями.

## 📊 Результати вимірювання схожості (Cosine Distance)

Для базового зображення (біле коло на синьому тлі) було виміряно косинусну відстань до його модифікованих версій:

| Зображення / Зміна | Косинусна відстань | Рівень подібності | Опис візуальних змін |
| :--- | :--- | :--- | :--- |
| **Оригінал** | 0.00000 | **Ідентично** | Базовий референс |
| **Зсув об'єкта (Crop/Shift)** | 0.21183 | **Високий** | Зсув білого кола до краю зображення |
| **Зміна кольору (Червоний фон)** | 0.38578 | **Середній** | Перефарбування фону з синього на червоний |
| **Високе стиснення (JPEG 10%)** | 0.53721 | **Граничний** | Поява блочних артефактів JPEG, розмиття меж |
| **Абсолютно інше зображення** | 0.89073 | **Низький** | Однотонний зелений фон без фігур |

## 🔍 Аналіз та вибір Threshold (Поріг чутливості)

На основі отриманого розподілу косинусних відстаней ми визначили оптимальні режими роботи фільтра дублікатів:

### 1. Строгий поріг (Strict: `0.30`)
* **Сценарій використання**: Виявлення майже ідентичних фото.
* **Переваги**: Нульовий рівень помилкових спрацьовувань (false positives).
* **Недоліки**: Пропускає файли з серйозними колірними фільтрами чи сильним стисненням.

### 2. Оптимальний поріг (Balanced: `0.45` - **Рекомендовано за замовчуванням**)
* **Сценарій використання**: Виявлення серійних фотографій, кадрування та стиснених копій для месенджерів.
* **Переваги**: Добре захоплює зсунуті або злегка обрізані зображення, а також фотографії з різними профілями кольору (наприклад, sRGB vs Display P3).

### 3. М'який поріг (Lenient: `0.55`)
* **Сценарій використання**: Групування фотографій однієї сцени.
* **Переваги**: Знаходить дублікати навіть після екстремального стиснення або ресайзу.
* **Недоліки**: Можливі поодинокі помилкові спрацьовування на схожих текстурних сценах.

## 🛠️ Рекомендація з інтеграції в UI
У налаштуваннях аналізу дублікатів додатку слід запропонувати слайдер регулювання чутливості зі значенням **0.45 за замовчуванням**, маркуючи крайні зони як:
- **Низька чутливість** (поріг 0.25 - тільки точні копії)
- **Збалансована** (поріг 0.45)
- **Висока чутливість** (поріг 0.55 - схожі сцени, серії знімків)
