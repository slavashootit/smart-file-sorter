# v1.5.1-cleanup — Remove Profiles and Semantic Search

> Design spec created: 2026-05-21

## Context
Smart File Sorter (Swift 5.9 / SwiftUI, native macOS). This is a patch release
to remove two dead UX features before continuing v1.6.0 "Polish".
Pure cleanup PR — no new features, no visual changes, no refactors.

## Scope: REMOVE COMPLETELY

### 1. Profile system (Photography / Work / Home)
- Model: `Profile` struct and all variants
- Manager: `ProfileManager` singleton
- UI: profile picker in sidebar header + MenuBarView
- AppState bindings: `activeProfile`, `selectedProfile`
- Persistence: UserDefaults profile keys — silently ignored

### 2. Semantic Search
- View: `SemanticSearchView` and nav route
- Engine: `SemanticSearchEngine` (Vision classify + embeddings SQLite)
- Entry points: sidebar link, route case
- SQLite: `embeddings` table — DROP TABLE IF EXISTS in migration

### 3. NLContextualEmbedding
- **Decision: NOT USED** — grep found 0 callsites. SemanticSearchEngine uses
  `NaturalLanguage` import but only for `NLLanguage` — entire file deleted.

## Migration
- `profiles.json` on disk: do NOT read, do NOT delete. Silent ignore.
- `embeddings` SQLite table: DROP TABLE IF EXISTS in HistoryManager migration.
- Other tables untouched.

## DO NOT TOUCH
- Vision framework (VNClassifyImageRequest, VNGenerateImageFeaturePrintRequest)
- Rules engine, templates, analytics, duplicates, sunburst
- DT design system, v1.6.0 Polish components
- FSEvents watcher, HistoryManager (except profile_name column — KEEP for data compat)
