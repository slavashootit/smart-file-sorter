visual changes, no refactors.

### 3. NLContextualEmbedding
- **Decision: NOT USED** — 0 callsites. Entire SemanticSearchEngine file deleted.

## Migrations (run on first launch after upgrade)

| Legacy artifact | Migration |
|-----------------|-----------|
| `rules_Home.json` | `FileManager.moveItem` → `rules.json` |
| `watcher_paths_Home` UserDefault | Copy to `watcher_paths`, remove old key |

| `embeddings` SQLite table | `DROP TABLE IF EXISTS embeddings` |
