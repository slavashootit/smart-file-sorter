# 📂 Розумний сортувальник файлів (Smart File Sorter)

[![Завантажити останню версію для macOS](https://img.shields.io/badge/Завантажити-macOS-blue.svg?style=for-the-badge&logo=apple)](https://github.com/slavashootit/smart-file-sorter/releases/latest/download/SmartFileSorter.dmg)

Преміальний настільний додаток для швидкого та безпечного впорядкування файлів у вашій системі з сучасним інтерфейсом у стилі **glassmorphism** (ефект матового скла) та динамічною підсвіткою.

Починаючи з версії **v1.4 "Consolidation"**, додаток повністю переписано на **Swift та SwiftUI** для забезпечення максимальної продуктивності на macOS. Попередня версія на Python збережена в репозиторії як CLI-інструмент для автоматизації та резервного копіювання.

---

## ✨ Основні можливості (Native Swift)

- **⚡️ Надшвидке сканування**: Використовує алгоритм `XXHash64` та розумний кеш у SQLite (`hash_cache.db`) з автоматичним очищенням застарілих записів (30 днів), що прискорює повторне сканування на **~78%**.
- **🔄 Асинхронний Engine (Async/Await)**: Процес сортування виконується повністю у фоновому потоці через `AsyncStream`. Завдяки буферизації `.bufferingNewest(100)` інтерфейс залишається плавним навіть при обробці мільйонів файлів.
- **🛡️ Транзакційна історія (SQLite)**: Усі сесії сортування та операції переміщення файлів записуються в базу даних `history.db`. Ротація зберігає останні 50 сесій.
- **↩️ Безпечне скасування (Undo)**: У разі переривання сортування поточна сесія маркується як `is_cancelled = 1` та може бути повністю скасована (файли повернуться на місце, а створені папки видаляться).
- **⚙️ Налаштування правил (ConfigManager)**: Гнучке редагування виключень (`exclusions.json`) та категорій (`categories.json`) безпосередньо через інтерфейс налаштувань.
- **🚀 Апаратна оптимізація**: Фоновий прорахунок метаданих відео (`AVURLAsset`) та індексація Spotlight (`MDItemCreate`) без блокування інтерфейсу.

## 🛠️ Вимоги та встановлення

### Системні вимоги:
* **macOS 13.0** або новіша.
* Встановлений **Xcode 15.0+** (або Xcode Command Line Tools) для збірки з вихідного коду.

### Збірка та запуск (Swift CLI / Xcode):
Ви можете скомпілювати та запустити проект через термінал:
```bash
# Збірка проекту
swift build -c release

# Запуск додатка
swift run SmartFileSorter
```

### Запуск тестів:
Проект постачається з повним покриттям тестів `XCTest`:
```bash
swift test --parallel --enable-code-coverage
```

### Запуск бенчмарку продуктивності:
Для тестування швидкості хешування та сканування запустіть Swift скрипт у папці `tools/`:
```bash
swift run --package-path . -c release benchmark
```

## 🐍 Python CLI-версія (Fallback)
Якщо вам потрібен консольний варіант для автоматизації в cron-таблицях або роботи через скрипти, використовуйте код у папці `/python/`:

1. Перейдіть до папки:
   ```bash
   cd python
   ```
2. Встановіть залежності:
   ```bash
   pip3 install -r requirements.txt
   ```
3. Запустіть скрипт:
   ```bash
   python3 file_sorter.py --source /path/to/folder --mode type
   ```

## 🛡️ Безпека та конфіденційність
Програма **нічого безповоротно не видаляє** (за винятком явного використання вкладки очищення дублікатів/кошика). Якщо під час переміщення файлу виникає конфлікт імен, додається унікальний числовий індекс, щоб уникнути перезапису даних.
