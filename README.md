# 📂 Розумний сортувальник файлів (Smart File Sorter)

Преміальний настільний додаток для швидкого та безпечного впорядкування файлів у вашій системі з сучасним інтерфейсом у стилі **glassmorphism** (ефект матового скла) та динамічною підсвіткою.

---

## ✨ Основні можливості

- **2 режими групування**:
  - **За типами**: автоматичне сортування файлів по тематичних папках (*Відео, Зображення, Документи, Аудіо, Архіви* та *Інші файли*).
  - **За датами**: розподілення по папках на основі року та місяця створення файлів (наприклад, `2026/Травень/`).
- **Вибіркове сортування**: можливість вмикати/вимикати окремі категорії файлів перед запуском.
- **🔍 Пошук та ізоляція дублікатів**: інтелектуальне виявлення копій за допомогою MD5-хешування та автоматичне перенесення дублікатів до папки `/Дублікати`.
- **↩️ Безпечний Undo (Скасування змін)**: повне відновлення вихідного стану (переміщення файлів назад та видалення створених порожніх папок) у випадку помилки.
- **👀 Попередній перегляд (Preview)**: запуск без реальних змін на диску для перевірки плану сортування.
- **⌨️ Гарячі клавіші**:
  - `⌘ + O` — вибрати папку.
  - `⌘ + Enter` — почати сортування.
  - `⌘ + L` — очистити журнал терміналу.

## 🚀 Як встановити та запустити (для macOS)

### Варіант 1: Завантаження готового додатка (Рекомендовано)
1. Завантажте архів `Сортувальник_файлів_macOS.zip` (можна знайти в розділі **Releases** або за посиланням на GitHub).
2. Розпакуйте архів — ви отримаєте готовий додаток **`Сортувальник файлів.app`**.
3. Перетягніть його на **Робочий стіл** або в папку **Програми (Applications)**.
4. Двічі клацніть для запуску.
   > **Примітка для macOS**: При першому запуску macOS може запитати дозвіл, оскільки додаток підписано локальним сертифікатом розробника. Просто перейдіть у *Системні параметри -> Безпека та приватність* та дозвольте запуск.

### Варіант 2: Запуск із вихідного коду (для розробників)
Якщо у вас встановлений Python 3 та менеджер пакетів pip:

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/ВАШ_НІК/file_sorter.git
   cd file_sorter
   ```
2. Встановіть необхідні залежності:
   ```bash
   pip3 install -r requirements.txt
   ```
3. Запустіть додаток:
   ```bash
   python3 file_sorter_web.py
   ```

## 📦 Як скомпілювати у `.app` самостійно
Якщо ви внесли зміни в код і хочете створити нову версію `.app` додатка:
```bash
osacompile -o "Сортувальник файлів.app" -e 'do shell script "cd /шлях/до/проекту && /opt/homebrew/bin/python3 file_sorter_web.py &"'
```

## 🛡️ Безпека
Програма гарантовано **нічого не видаляє**. Файли лише переміщуються. Якщо під час переміщення виникає конфлікт імен, оригінальний файл не перезаписується — замість цього до назви додається унікальний індекс.
